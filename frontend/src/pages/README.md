# Mini ERP CRM System

A full-stack ERP and CRM application for managing customers, products, inventory, and sales operations.

## Features

- User Authentication using JWT
- Customer Management
- Product Management
- Inventory Management
- Challan Management
- Dashboard
- Role Based Access Control

## Technologies Used

### Frontend
- React.js
- Axios
- CSS

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma ORM

### Database
- PostgreSQL
